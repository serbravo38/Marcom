Abre Postman > Clic en Import > Selecciona marcom_postman_collection.json para ver todos los endpoints con tests.

marcom_postman_collection.json

2. En Terminal con un Clic

ejecutar_pruebas.bat

3. Con Newman (CLI Automático)

Ejecuta: npx newman run marcom_postman_collection.json -e marcom_postman_environment.json
